# ASP Studio Photo — исходники `vPhoto.html`

Фотореалистичная версия планировщика. Готовый файл — `../vPhoto.html` (один HTML без внешних зависимостей, работает офлайн, как и классический `vClaude.html`). Классический планировщик не изменён и доступен по ссылке «Классическая версия».

```
src/main.js       2D-редактор (перенесён из vClaude.html) + интерфейс каталога и материалов
src/engine.js     3D: PBR, ACES, окружение, мягкие тени, GTAO, время суток, снимок
src/catalog.js    каталог (120+ параметрических моделей) и их построители
src/materials.js  процедурные текстуры (дерево, ткани, мрамор, плитка…) и материалы
src/demo.js       пример меблированной квартиры
template.html     разметка и стили
```

Сборка (Node 18+):

```
cd photo-src
npm install
npm run build      # пересобирает ../vPhoto.html
```

Файлы проектов (.json) совместимы с классической версией в обе стороны: новые поля (материалы, отделка) старая версия просто игнорирует.
